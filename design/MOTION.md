# PartyGame 当前动效

用户批准的丰富动画已在 React 状态与 CSS 中实现。下表取自 `src/styles.css`、`src/screens.jsx` 和 `src/App.jsx`，是当前行为记录；原六场景分镜保留为视觉参考。

## 动态语言

牌桌上的物件承载状态：筹码落座、准备盖章、牌堆洗牌、卡片入池、封印分开、结束摊牌。通用缓动为 `cubic-bezier(0.16, 1, 0.3, 1)`。阅读中的任务正文保持静止。

| 场景 | 触发与当前动作 | 时间 | 最终状态 |
| --- | --- | --- | --- |
| 入口牌堆 | 入口插画一次短升降与倾斜后落稳，无持续悬浮 | 1100ms | 加入和创建入口可用 |
| 筹码落座 | 头像入场短落下并回弹；准备勾章另行触发 | 420ms；盖章 180ms | 昵称与准备文字可读 |
| 洗牌发牌 | 成功分配后两张卡交错移动，进入游戏按钮始终可跳过 | 1200ms | 原有分配结果不改变 |
| 掀开偷看 | 本人秘密正文出现时短掀开与淡入 | 220ms | 按住期间可读；松开立即切换收起状态，无等待退出动画 |
| 卡牌入池 | 投稿成功后，预览向右上方可见牌堆缩小旋转；随后回到任务池 | 560ms | 题量与本人投稿已更新 |
| 封印弹开 | 本人禁忌解除视图中两半封印向两侧分离 | 650ms | 条件可读，秘密任务继续 |
| 全桌摊牌 | 牌堆展开为扇形；玩家回顾逐行出现 | 扇形 700ms；每行 500ms，间隔 65ms | 全部本局任务可滚动阅读 |
| 纸屑 | 解除与揭晓的短暂物件反馈 | 900ms，逐片间隔 24ms | 不覆盖交互、不循环 |

## 次级反馈

按钮按下缩放到 0.97，变换和背景过渡 140ms；开关位移 160ms。模式选择、准备印章、提示条和对话框采用 180ms 反馈。页面正文未实现持续摆动，也没有音效设置；原分镜中的可选音效仍非产品功能。

## 保密与减少动态效果

自己的未解除禁忌由服务端过滤，不进入动画背面。秘密任务支持指针按住、键盘按住与独立点按替代；松开、取消、捕获丢失、失焦、页面隐藏或离页时收起。游戏中的完整遮盖状态由应用管理，动画不能延迟保密动作。

`prefers-reduced-motion: reduce` 关闭全部关键帧动画、隐藏纸屑，将过渡时长设为 80ms。投稿预览变为静止的 0.4 不透明度反馈，秘密正文取消变换。投稿 560ms 和发牌 1200ms 的 JavaScript 计时仍存在；发牌可直接跳过。此分支已在代码中实现，不等同于已独立完成运行时验收。

实体手机长按、系统后台切换、辅助技术与减少动态效果的独立运行验证尚待完成。不得将浏览器截图或分镜当作这些验证的证据。
