# PartyGame 设计与实现记录

用户批准的「桌游俱乐部」方向已实现为可运行的手机聚会游戏，并已部署至用户指定的私有服务器。此目录保留七张最终设计板、七页 PDF 与源于当前代码的交互、动效说明。设计板中的昵称、房间码与任务是演示内容，PDF 本身不是可交互原型。

本地 `.impeccable/design.json` 是 schemaVersion 2 面板扩展，配合 DESIGN.md 的 token 使用；该目录属于被忽略的工作记录，不是公开仓库依赖。

`01-entry.png`、`05-modes.png` 和 `06-motion.png` 是被相应 `-v2` 文件替代的旧版，不进入最终设计板索引。旧稿保留作过程记录。原七页 PDF 继续作为已批准的历史参考，当前按钮、字体和响应式尺寸以代码及 DESIGN.md 为准。

实现使用自托管 Noto Sans SC、Lucide 图标与可复用插画。12 款头像使用 ID 0–11：原头像图集保留 0–5，新增独立 PNG 承载 6–11；大厅、游戏和揭晓复用同一 ID。灯照桌面、秘密牌背、禁忌牌、可拆封印、投稿目标牌堆及揭晓扇形构成实体桌游场景。

公开 PNG 和提示词的本机路径已脱敏，PNG 像素与透明通道保持不变。原始记录仅保留在被忽略的本地备份中。设计板目录中的历史提示词与实现素材提示词应分别按各自索引读取。

自动测试与跨主机 API / 浏览器流程已有验证，含 12 名不同头像玩家完整回合。浏览器截图覆盖 320、390、442、1280、1440 宽度。重建后的视觉复核所列修正已通过定向验收；整桌面与手机区域不匹配的机械响应式比对门槛仍开放。实体手机、系统后台遮盖与减少动态效果的独立运行验收尚待完成。
